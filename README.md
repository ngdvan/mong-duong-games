# Mông Dương — 16 game 2D, 96 màn

[Chơi trên GitHub Pages](https://ngdvan.github.io/mong-duong-games/MD_game/?v=phaser-1)

Ba game top-down (Ca đầu tiên, Theo chân người kèm cặp, Một vòng khu sinh hoạt) và platformer Bậc thang đầu ca dùng Phaser 3.90.0. Mười hai game còn lại dùng Three.js r180 với hình phẳng và camera trực giao. Chỉ tải engine của game đang chơi; không tải Three.js khi chơi game Phaser.

Mỗi game có sáu màn tăng độ khó, thời gian giới hạn, xu thưởng lần đầu và gợi ý mua bằng xu. Tiến độ, xu và gợi ý đã mua giữ cùng khóa lưu trữ. Không dùng game chữ hoặc khối 3D.

Bản chơi thử phục vụ ôn tập, không thay thế huấn luyện thực hành. Nội dung tham khảo MD-01/02/03; cần đơn vị đối chiếu tài liệu hiện hành. Kho công khai không chứa tài liệu nguồn nội bộ, cấu hình riêng hoặc thông tin đăng nhập.

Xem [Phaser](MD_game/PHASER.md), [Three.js](MD_game/THREEJS.md), [thiết kế](MD_game/GAME_IDEAS_2D.md) và [luật chiến dịch](MD_game/CAMPAIGN.md).
