# Mông Dương — 16 game 2D dùng Three.js

[Chơi trên GitHub Pages](https://ngdvan.github.io/mong-duong-games/MD_game/?v=flat-2d-1)

96 màn có độ khó tăng dần, thời gian giới hạn, xu thưởng và gợi ý mua bằng xu. Tất cả cảnh chơi là 2D với hình phẳng/sprite và camera trực giao vuông góc, được Three.js hiển thị bằng WebGL. Không dùng mô hình khối 3D, góc nhìn phối cảnh/isometric hoặc game text-based.

Đây là bản chơi thử phục vụ ôn tập. Nội dung tham khảo MD-01/02/03; cần đơn vị đối chiếu tài liệu hiện hành trước khi dùng huấn luyện. Kho công khai chỉ chứa các tệp game được cho phép xuất bản, không chứa tài liệu nguồn nội bộ hoặc thông tin cấu hình riêng.

Xem [kiến trúc](MD_game/THREEJS.md), [thiết kế](MD_game/GAME_IDEAS_2D.md) và [luật chiến dịch](MD_game/CAMPAIGN.md).
